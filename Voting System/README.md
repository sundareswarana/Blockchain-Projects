## Blockchain Voting System

A simple Ethereum-based voting application developed using Solidity. This smart contract allows users to add candidates, cast votes, and securely track vote counts on the blockchain. The system prevents double voting by ensuring that each wallet address can vote only once.

### Features

* Add candidates to the election
* 
* Cast votes securely
* 
* Prevent double voting using wallet address validation
* 
* View candidate vote counts
* 
* Deploy and test using Remix IDE, Ganache, and MetaMask
* 

### Technologies Used

* Solidity
* 
* Ethereum Blockchain
* 
* Remix IDE
* 
* Ganache
* 
* MetaMask

### Learning Outcomes

This project helped in understanding smart contracts, blockchain transactions, mappings, structs, arrays, and decentralized application (DApp) development concepts.
