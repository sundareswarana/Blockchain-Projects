The Blockchain Certificate Verification System is a simple Ethereum smart contract developed using Solidity.

It demonstrates how blockchain technology can be used to issue and verify digital certificates in a secure, transparent, and tamper-resistant manner.


The application allows an authorized user to issue certificates with a unique certificate ID, student name, and course name. Anyone can verify the authenticity of a certificate using its certificate ID.
