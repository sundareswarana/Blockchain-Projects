The application provides a blockchain-based approach for registering and retrieving employee information, with transactions processed through a MetaMask wallet and recorded on a local Ethereum blockchain.

Technologies Used

• Solidity

• Ethereum

• Remix IDE

• Ganache

• MetaMask

• Ethers.js

• HTML, CSS & JavaScript

Key Features

✔ Employee Registration using Employee ID

✔ Employee Search and Retrieval

✔ Smart Contract-based Data Storage

✔ MetaMask Wallet Integration

✔ Blockchain Transaction Processing

✔ Employee Photo Upload and Display

✔ Interactive Web-based Interface
